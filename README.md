# K-Means and K-Means++

C++ implementation comparing K-Means and K-Means++ using runtime and inertia.

## 1. Install Dependencies

```bash
py -m pip install numpy scikit-learn
```

## 2. Generate Datasets

```bash
py data/db.py
```

- Choose `1` for predefined datasets.
- Choose `2` to generate a custom dataset.

## 3. Compile

```bash
g++ -g -O0 -std=c++17 -Isrc/cpp src/cpp/test_kmeans.cpp src/cpp/kmeans_base.cpp src/cpp/kmeans_plus_plus.cpp -o test_debug.exe
```

## 4. Run

Pass the dataset CSV files as arguments. For example:

```bash
./test_debug.exe data/small_points.csv data/medium_points.csv data/large_points.csv data/high_dim_points.csv data/overlap_points.csv
```

For a custom dataset, replace "custom_test" in "custom_test_points" with the file name you chose:

```bash
./test_debug.exe data/custom_test_points.csv
```

The cluster count is detected automatically from the metadata generated by `db.py`.

## 5. View Results

```bash
explorer.exe results.csv
```

Results include dataset size, dimensions, `k`, runtime, and inertia for both algorithms.
